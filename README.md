# RecomputeCheck: Verifying AI-Written Data Reports by Recalculating the Numbers

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests: Passing](https://img.shields.io/badge/tests-passing-brightgreen.svg)](tests/)

**RecomputeCheck** is a post-hoc, deterministic verification system for auditing AI-generated analytical reports against tabular datasets (CSV). When an LLM writes an analytical summary of a dataset, RecomputeCheck extracts every numeric claim, maps it to a safe AST-constrained Pandas expression over the actual tabular data, re-executes the calculation, and flags each claim as **VERIFIED**, **CONTRADICTED**, or **NOT_COMPUTABLE**, calculating a comprehensive **Recomputation Fidelity Score (RFS)**.

---

## Key Features

1. **Post-Hoc Verification**: Audits existing reports generated by any LLM without requiring generation-time tokens or model checkpoint access.
2. **Deterministic Recomputation**: Uses real tabular execution (Pandas/NumPy) rather than probabilistic resampling or fuzzy text retrieval.
3. **AST Safety Sandbox**: Validates syntax trees with strict whitelisting to prevent arbitrary code execution vulnerabilities.
4. **Tolerance-Aware Evaluation**: Supports dual relative ($\le 2\%$) and absolute ($\le 0.5$) thresholds to account for natural rounding.
5. **Interactive UI & Audit Workbench**: Highlights claims, displays generated Pandas expressions, shows numeric deltas, and visualizes benchmark comparisons.

## Reproducing Empirical Experiments

Run the baseline comparisons and ablation study:

```bash
PYTHONPATH=. python3 experiments/run_benchmarks.py
```

Results are saved to `experiments/results.json`:
- **RecomputeCheck**: Accuracy 1.0, Precision 1.0, Recall 1.0, F1 1.0 (Coverage 100%)
- **Raw LLM**: F1 0.0 (Misses 100% of hallucinations)
- **SelfCheck Resampling**: Recall 0.40, F1 0.5714 (Repeats systematic hallucinations)
- **Semantic Cell Retrieval**: Precision 1.0, but Coverage collapses to 20.0% on aggregations.
