Project Title: RecomputeCheck

Auditing AI Math & Tabular Hallucinations by Re-Executing the Real Data

---

## 1. Introduction

Artificial Intelligence (AI) models like ChatGPT and Gemini are great at writing human-like sentences. However, when you ask them to summarize spreadsheets, business data, or financial tables, they frequently make silly math mistakes or invent fake numbers. This is called **AI hallucination**.

**RecomputeCheck** solves this problem. It acts like a strict math teacher checking an AI’s homework. Instead of trusting what the AI typed, it reads every number, opens your original data file, redoes the exact math, and marks every statement as **VERIFIED**, **CONTRADICTED**, or **NOT COMPUTABLE**.

---

## 2. Project Overview

**RecomputeCheck** is a full-stack automated verification tool designed to audit data reports generated by Large Language Models (LLMs).

- **Input:** A raw dataset (CSV spreadsheet) and an AI-generated report summarizing that data.
- **Process:** The system extracts every number, figures out what formula was used, writes code to recalculate it against the real data, and compares the results.
- **Output:** A color-coded audit report with a **Fidelity Score (0–100%)**, discrepancy percentages, and the exact code used to prove or disprove each claim.

---

## 3. Literature Review (What Researchers Did Before)

In recent AI safety and evaluation research, checking if an AI is telling the truth has usually been done in two ways:

1. **Self-Consistency & Confidence Scoring (e.g., Cleanlab TLM):**
   The system asks the AI the same question several times. If the answers differ, it flags the answer as low-confidence.
   *Limitation:* Even if an AI is 100% confident, its math can still be completely wrong.
2. **Text-Based Fact Checking (e.g., RAG / Semantic Search):**
   The system searches through text documents to find matching sentences.
   *Limitation:* Text search cannot calculate math (e.g., finding the average churn rate of customers over 50 years old).

**Where RecomputeCheck Fits:**
Recent papers (such as Program-Aided Language Models and Code-as-Policies) show that the only reliable way to check math is by running actual code. RecomputeCheck builds on this principle by turning every numerical claim into deterministic execution code.

| -------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------- |

## 5. Problem Statement

When business managers, doctors, and financial analysts use AI to summarize tables, they cannot easily tell if the numbers in the summary are real or made up.

Checking dozens of numbers by hand in Excel takes hours. Blindly trusting wrong numbers can lead to bad business decisions, lost money, or failed audits. There is a critical need for an automated, zero-trust system that recalculates numbers straight from raw source data.

---

## 6. Objectives and Scope

### Objectives:

1. **Detect AI Math Lies:** Automatically identify hallucinated percentages, averages, counts, and totals.
2. **Deterministic Ground-Truth Recomputation:** Execute code directly against the uploaded CSV without relying on LLM guesses.
3. **Transparent Audit Trails:** Give users a clear breakdown showing the claimed number, recomputed number, discrepancy %, and verdict.
4. **Interactive Dashboard:** Provide an easy-to-use web interface where anyone can upload a CSV, generate or paste an AI report, and see the results instantly.

### Scope:

- **In Scope:** Tabular data (CSV files), numerical claims (sums, averages, counts, rates, min/max, subgroup filters), side-by-side claim inspection, and benchmark experiment metrics.
- **Future Scope:** Multi-table SQL database joins, PDF document table parsing, and automated report auto-correction (auto-rewriting the text with the true numbers).

## 8. Summary of Verification Grades

- 🟢 **VERIFIED:** The AI told the truth. The recomputed number matches the claim.
- 🔴 **CONTRADICTED:** The AI made up a number. RecomputeCheck highlights the discrepancy and provides the real value.
- 🟡 **NOT COMPUTABLE:** The data file does not contain the columns or information needed to verify the claim.












# RecomputeCheck: Verifying AI-Written Data Reports by Recalculating the Numbers

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests: Passing](https://img.shields.io/badge/tests-passing-brightgreen.svg)](tests/)

**RecomputeCheck** is a post-hoc, deterministic verification system for auditing AI-generated analytical reports against tabular datasets (CSV). When an LLM writes an analytical summary of a dataset, RecomputeCheck extracts every numeric claim, maps it to a safe AST-constrained Pandas expression over the actual tabular data, re-executes the calculation, and flags each claim as **VERIFIED**, **CONTRADICTED**, or **NOT_COMPUTABLE**, calculating a comprehensive **Recomputation Fidelity Score (RFS)**.

---

## Key Features

1. **Post-Hoc Verification**: Audits existing reports generated by any LLM without requiring generation-time tokens or model checkpoint access.
2. **Deterministic Recomputation**: Uses real tabular execution (Pandas/NumPy) rather than probabilistic resampling or fuzzy text retrieval.
3. **AST Safety Sandbox**: Validates syntax trees with strict whitelisting to prevent arbitrary code execution vulnerabilities.
4. **Tolerance-Aware Evaluation**: Supports dual relative ($\le 2\%$) and absolute ($\le 0.5$) thresholds to account for natural rounding.
5. **Interactive UI & Audit Workbench**: Highlights claims, displays generated Pandas expressions, shows numeric deltas, and visualizes benchmark comparisons.

## Reproducing Empirical Experiments

Run the baseline comparisons and ablation study:

```bash
PYTHONPATH=. python3 experiments/run_benchmarks.py
```

Results are saved to `experiments/results.json`:
- **RecomputeCheck**: Accuracy 1.0, Precision 1.0, Recall 1.0, F1 1.0 (Coverage 100%)
- **Raw LLM**: F1 0.0 (Misses 100% of hallucinations)
- **SelfCheck Resampling**: Recall 0.40, F1 0.5714 (Repeats systematic hallucinations)
- **Semantic Cell Retrieval**: Precision 1.0, but Coverage collapses to 20.0% on aggregations.
